# 远程ADB助手 (AdbRemoteAssistant) - 独立自愈重连版 (v1.0.2)

基于 **纯 Kotlin 内嵌式 ADB 协议引擎（dadb）** 实现的完全自包含远程安卓调试工具，彻底摆脱外部软件与二进制依赖，专为 Android 16（小米澎湃 3）与多架构设备优化。

---

## v1.0.2 重大体验优化

1. **持续后台心跳监测回路（Heartbeat Monitor）**：
   * 后台微型协程探针每 4 秒轮询一次链路健康，彻底告别“假在线”；
   * 顶部新增常驻**设备连接状态横幅**（带绿/橙/红实时状态指示灯），在所有标签页均可见。
2. **全流程透明自愈重连（Self-Healing Auto-Reconnect）**：
   * 上传安装 APK、拉取应用列表、停止应用前**自动执行链路预检**；
   * 若发现网络波动或连接中断，**系统自动在后台执行静默自愈重连**，用户不需要每次特意跑回首页重复点击“连接”。
3. **设备记忆与启动自连**：
   * 自动持久化记住最后一次成功连接的 IP 与端口；
   * 每次打开 App 自动恢复输入并自动尝试握手，实现开箱即用。
4. **完全自包含与全架构支持**：
   * 免 Root、免 Shizuku、免电脑配置，双向兼容 64位（arm64-v8a）与 32位（armeabi-v7a）。
